# Product research: 11 researched kit entries

Researched 2026-09-26 for `src/profiles/aron/kit/`. The lead writes tens-unit.md.

## How the ASINs were checked, and why every entry is still `draft: true`

- WebFetch to `www.amazon.es` and `amazon.es` returns `EGRESS_BLOCKED`, and so does curl from Bash (the proxy returns 403 on CONNECT). In this session WebFetch was also blocked on every other domain I tried: anker.com, support.anker.com, bestbuy.com, camelcamelcamel, wikipedia.org. **No ASIN could be opened directly.**
- I found every ASIN through WebSearch restricted to `amazon.es` (`allowed_domains: ["amazon.es"]`). Each chosen ASIN showed up in the search index as an `amazon.es/.../dp/<ASIN>` URL whose indexed page title names the product. For several I also ran a search on the ASIN itself. That is strong evidence the listing exists, but it does not meet the brief's bar for VERIFIED (seeing it resolve through WebFetch). So **every ASIN below is UNVERIFIED and every entry has `draft: true`.**
- To confirm, open each link in a browser. Check the product matches, it is in stock, and it is sold or shipped by the brand or by the marketplace itself. Then set `draft: false`.
- None of the picks is a marketplace own brand. Own-brand options that came up in searches were excluded: an own-brand commercial anti-fatigue mat (B08CW6ZFHC) and own-brand high-density foam rollers. No entry puts the marketplace's name in `title`, `product` or any heading.
